# 難波商店街地域BCPマップウェブアプリケーション DB設計書

## 1. データベース概要

本システムでは、以下の主要テーブルを使用する。

- users
- stores
- emergency_contacts
- disaster_events
- reports
- damage_items
- report_damage_items
- support_requests
- photos
- notifications
- notification_targets
- emergency_supplies
- operation_logs

## 2. users テーブル

ユーザー情報を管理する。

| カラム名 | 型 | 内容 |
|---|---|---|
| id | integer | ユーザーID |
| name | varchar | 氏名 |
| email | varchar | メールアドレス |
| password_hash | varchar | パスワードハッシュ |
| role | varchar | 権限区分 |
| store_id | integer | 所属店舗ID |
| is_active | boolean | 有効状態 |
| last_login_at | datetime | 最終ログイン日時 |
| created_at | datetime | 登録日時 |
| updated_at | datetime | 更新日時 |

role の値は以下とする。

- store_user
- admin
- external
- system_admin

| カラム名 | 型 | 内容 |

| manager_name | varchar | 担当者名 |
| phone | varchar | 電話番号 |
| email | varchar | メールアドレス |
| note | text | 備考 |
| created_at | datetime | 登録日時 |
| updated_at | datetime | 更新日時 |

| カラム名 | 型 | 内容 |

## 6. reports テーブル

店舗からの報告情報を管理する。

| カラム名 | 型 | 内容 |
|---|---|---|
| id | integer | 報告ID |
| disaster_event_id | integer | 災害イベントID |
| store_id | integer | 店舗ID |
| safety_status | varchar | 安否状況 |
| business_status | varchar | 営業状況 |
| has_damage | boolean | 被害有無 |
| has_support_request | boolean | 支援要請有無 |
| memo | text | メモ |
| is_proxy | boolean | 代理入力フラグ |
| proxy_method | varchar | 確認方法 |
| reported_by | integer | 報告者ID |
| reported_at | datetime | 報告日時 |
| created_at | datetime | 登録日時 |
| updated_at | datetime | 更新日時 |

safety_status の値は以下とする。

- safe
- damaged
- checking
- evacuated
- unknown

business_status の値は以下とする。

- open
- partially_open
- closed
- preparing
- checking
- unknown
