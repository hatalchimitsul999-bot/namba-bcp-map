# 難波商店街地域BCPマップウェブアプリケーション 基本設計書

## 1. システム概要

本システムは、難波商店街における災害時の情報共有と復旧判断を支援するWebアプリケーションである。

各店舗は、スマートフォンのブラウザから安否状況、被害状況、営業状況、支援要請を報告する。商店街管理者は、PC、タブレット、スマートフォンのブラウザから管理画面にアクセスし、各店舗の状況をBCPマップおよび管理ダッシュボードで確認する。

## 2. システム構成

本システムは以下の構成とする。

- 利用者端末
  - スマートフォン、タブレット、PCのブラウザからアクセスする
- フロントエンド
  - 店舗ユーザー向け画面、管理者向け画面、外部機関向け閲覧画面を提供する
- バックエンド
  - ログイン認証、店舗情報管理、報告登録、支援要請管理、通知処理、地図表示用データ取得などを行う
- データベース
  - 店舗情報、ユーザー情報、災害イベント情報、報告情報、支援要請情報、写真情報、防災備品情報などを保存する
- 地図サービス
  - 店舗位置や被害状況を地図上に表示するため、地図APIまたは地図ライブラリを利用する
- 通知サービス
  - 一斉通知や再通知に使用する

## 6. システムモード

### 6.1 平常時モード

平常時モードは、災害時にシステムを円滑に利用するための準備機能である。

主な機能は以下の通りである。

- 店舗情報管理
- 緊急連絡先管理
- 防災訓練管理
- 通知テスト
- 防災備品管理

平常時モードでは、通常商品の在庫管理や売上管理など、店舗の日常業務全般は対象外とする。

### 6.2 災害時モード

災害時モードは、災害発生後に各店舗の状況を収集し、商店街全体の状況を把握するための機能である。

主な機能は以下の通りである。

- 災害時モード切替
- 一斉通知
- 安否確認
- 被害状況報告
- 営業状況共有
- 写真投稿
- 支援要請
- 未報告店舗一覧
- 代理入力
- BCPマップ表示
- 管理ダッシュボード
- 外部機関向け閲覧

## 9. BCPマップ設計

BCPマップでは、店舗ごとの状況を地図上に表示する。

| 状態 | 表示内容 |
|---|---|
| 営業可能 | 営業を継続できる店舗 |
| 一部営業可能 | 一部機能や時間を制限して営業できる店舗 |
| 営業停止 | 営業できない店舗 |
| 支援要請中 | 支援を求めている店舗 |
| 被害あり | 何らかの被害が報告されている店舗 |
| 状況未確認 | 報告がない店舗 |
| 復旧済み | 復旧作業が完了した店舗 |

マップ上の店舗を選択すると、店舗詳細、安否状況、被害状況、営業状況、支援要請、最終更新日時を表示する。

## 10. 通知設計

通知機能では、商店街管理者が店舗ユーザーに対して安否確認や被害報告を依頼する。

初期段階では以下を想定する。

- 一斉通知
- エリア別通知
- 未報告店舗への再通知
- 訓練通知

将来的には以下との連携を検討する。

- メール通知
- LINE通知
- SMS通知

## 11. セキュリティ設計

- ログイン認証を行う
- ユーザー権限に応じて閲覧・編集範囲を制御する
- 外部機関には必要最小限の情報のみ表示する
- 通信はHTTPSで暗号化する
- 操作履歴を記録する
- 緊急連絡先や個人情報の表示範囲を制限する

## 12. 運用設計

平常時は、店舗情報と緊急連絡先を定期的に更新する。

災害時は、管理者が災害時モードへ切り替え、一斉通知を送信する。

店舗ユーザーは自店舗の状況を報告する。

未報告店舗については、管理者が電話確認を行い、代理入力する。

災害後は、報告内容や対応履歴を保存し、次回に向けて改善点を整理する。
