# 難波商店街地域BCPマップウェブアプリケーション 画面設計書

## 1. 共通画面仕様

本システムはWebアプリケーションとして提供する。

店舗ユーザー向け画面はスマートフォン利用を前提とし、ボタンを大きく、入力項目を少なくする。

管理者向け画面はPCおよびタブレット利用を前提とし、一覧性と地図表示を重視する。

外部機関向け画面は閲覧専用を基本とし、表示情報を制限する。

## 3. ログイン画面

### 画面ID

S001

### パス

`/login`

### 利用者

全ユーザー

### 目的

ユーザーがシステムにログインする。

### 表示項目

- システム名
- メールアドレス入力欄
- パスワード入力欄
- ログインボタン
- パスワード再設定リンク

### 入力項目

- メールアドレス
- パスワード

### 処理

- メールアドレスとパスワードを認証する
- 認証成功時、利用者区分に応じたトップ画面へ遷移する
- 認証失敗時、エラーメッセージを表示する

## 4. 店舗トップ画面

### 画面ID

S002

### パス

`/store`

### 利用者

店舗ユーザー

### 目的

店舗ユーザーが自店舗の状況報告を開始する。

### 表示項目

- 店舗名
- 現在のモード
- 最終報告日時
- 安否確認ボタン
- 被害状況報告ボタン
- 営業状況報告ボタン
- 支援要請ボタン
- 報告内容確認ボタン

### 処理

- 各報告画面へ遷移する
- 災害時モードでない場合は、訓練または準備画面を表示する

`/admin/map`

- 営業停止
- 支援要請中
- 被害あり
- 未報告
